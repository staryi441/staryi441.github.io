## Reporting a Vulnerability

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, send details to: **staryi441@proton.me** (PGP key available on GitHub profile).

Include:
- Project name and version
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 7 days
- **Fix Development**: Depends on severity (target: 30 days for critical)
- **Disclosure**: Coordinated after fix is released

## Scope

This policy covers:
- Source code in public repositories (staryi441/*)
- Release binaries (APK, .exe)
- This website (staryi441.github.io)

Out of scope:
- Third-party dependencies (report to upstream)
- Social engineering / phishing
- Issues requiring physical device access without user interaction

## Safe Harbor

We consider vulnerability research conducted under this policy to be:
- Authorized under applicable laws
- Not subject to legal action when conducted in good faith
- Eligible for acknowledgment in Hall of Fame (with permission)
