<strong>NetChecker</strong> — это легковесная и быстрая консольная утилита на .NET для комплексной проверки доступности сетевых ресурсов, анализа блокировок (DPI, фильтрация пакетов, TCP RST) и диагностики базовых сетевых протоколов.

**Режимы работы:**
- `check` — быстрая проверка списка хостов/порт
- `scan` — сканирование подсети на открытые порты
- `dpi` — анализ DPI/блокировок через TLS handshake
- `quic` — тест QUIC/HTTP/3 соединений
- `dns` — проверка DNS резолвинга (DoH/DoT/Plain)

**Пример:**
```bash
NetChecker check --targets "github.com:443,google.com:443" --protocol tcp,tls,quic --json
```

**Выход:** Структурированный JSON с таймингами, статусами TLS/QUIC, флагами блокировок.
