NetChecker

C# / .NET 8.0

NetChecker — это легковесная и быстрая консольная утилита на .NET для комплексной проверки доступности сетевых ресурсов, анализа блокировок (DPI, фильтрация пакетов, TCP RST) и диагностики базовых сетевых протоколов.

Мультипротокольный тест: TCP, UDP (DNS) и современный транспорт QUIC (HTTP/3).
Анализ блокировок: Распознавание сбросов соединений TCP RST во время TLS-handshake.
Автономное обновление: Синхронизация списков через GitHub API.
